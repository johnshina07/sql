# Task XIV – Business Intelligence and AI Data Preparation

## Objective
Prepare useful analytical datasets from e-commerce data using SQL reports, window functions, customer segmentation, and feature extraction.

## Concepts Used
- GROUP BY and aggregate reports
- RANK() and ROW_NUMBER()
- Customer spending segmentation
- Feature extraction for analytical and AI workflows
- Reusable customer-level dataset

## Tables
- TaskXIV_Customer
- TaskXIV_Product
- TaskXIV_Orders
- TaskXIV_Order_Details

## Execution
Run `Task-XIV.sql` from top to bottom in MySQL Workbench using MySQL 8.0 or later. Review the report queries and the final customer feature dataset.

## Note
The script creates isolated `TaskXIV_` tables with sample records. The generated features are illustrative and are not a trained AI model.

## Conclusion
This task demonstrates how SQL can transform transactional records into ranked reports, customer segments, and structured features suitable for downstream analytics and AI experiments.
