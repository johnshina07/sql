# Task XV – Industry Capstone Project: E-Commerce Intelligence Platform

## Objective
Build an integrated e-commerce database application that combines customer, product, order, payment, inventory, and analytical reporting modules.

## Modules Included
- Normalized customer, product, order, order-detail, payment, and inventory tables
- Sample business data
- Basic and advanced SQL reports
- Views for sales reporting
- Stored procedure for order placement
- Trigger-based stock maintenance
- Indexes for common searches
- Business insights and summary reports

## Execution
1. Open MySQL Workbench and select the database you want to use.
2. Open `Task-XV.sql`.
3. Execute the script from top to bottom.
4. Review the final business insight queries and object definitions.

## Note
The capstone uses its own `Capstone_` table names to avoid conflicts with Tasks I–XIV. It is a classroom demonstration schema, not a production payment system. Run it in a practice database because the script drops and recreates its own prefixed tables.

## Conclusion
The capstone integrates core DBMS concepts into an e-commerce intelligence platform and demonstrates how relational data, automation, transactions, indexing, and analytical SQL can support business decisions.
