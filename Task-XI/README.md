# Task XI – Database Automation using Views and Procedures

## Objective
Automate frequently used database reports and order operations using views, stored procedures, and functions.

## Concepts Used
- CREATE VIEW and SELECT from views
- Stored procedures with IN parameters
- Stored functions for sales calculations
- Reusable order-processing operations
- Testing database objects

## Tables
- TaskXI_Product
- TaskXI_Orders
- TaskXI_Order_Details

## Execution
1. Open MySQL Workbench and select your project database.
2. Open `Task-XI.sql`.
3. Execute the complete script from top to bottom.
4. Run the test SELECT and CALL statements at the bottom to verify the objects.

## Note
All table names use the `TaskXI_` prefix to avoid conflicts with tables from earlier tasks. The script uses MySQL 8.0 syntax.

## Conclusion
This task demonstrates how views, procedures, and functions reduce repeated SQL work and make order reporting and processing easier to maintain.
