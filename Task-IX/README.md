# Task IX – Sales and Customer Analytics System

## Objective
Analyze sales performance and customer purchasing behavior using SQL aggregate functions and analytical queries.

## Concepts Used
- COUNT(), SUM(), AVG(), MIN(), and MAX()
- Total sales and order-wise sales reports
- Top customers by purchase amount
- Best-selling product analysis
- Category-wise sales analysis
- JOIN, GROUP BY, and ORDER BY

## Tables
- Customer
- Product
- Orders
- Order_Details

## Expected Outcomes
- Calculate sales statistics using aggregate functions.
- Generate total sales and order-wise reports.
- Identify customers with the highest purchase amounts.
- Find best-selling products based on units sold.
- Compare sales performance across product categories.

## Tools Used
MySQL and MySQL Workbench.

## Note
This project uses sample data. Sales are calculated as quantity multiplied by product price, excluding taxes, discounts, and refunds.

## Conclusion
This project demonstrates how SQL can be used to analyze sales performance, understand customer purchasing behavior, and identify popular products and sales-performing categories.
